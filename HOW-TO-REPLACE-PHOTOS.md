# Как самой заменить фото на сайте

Все картинки лежат в папке `assets/images/`. Каждая картинка подключена в `index.html` одной строкой вида:

```html
<img src="assets/images/delyamer-66k.jpg" alt="Профиль Delyamer — 66 тыс. подписчиков" loading="lazy" />
```

## Чтобы заменить фото

1. Открой `index.html` в любом текстовом редакторе (подойдёт Блокнот / TextEdit / VS Code — не Word).
2. Найди нужную картинку через поиск (Ctrl+F / Cmd+F) — ищи либо по имени файла (например, `delyamer-66k.jpg`), либо по описанию в `alt="..."`.
3. Положи новую картинку в папку `assets/images/` — **дай ей уникальное английское имя без пробелов**, например `delyamer-new-photo.jpg` (это важно: если назвать файл так же, как уже существующий, он его перезапишет; если назвать так же, как временное имя с телефона типа `IMG_1234` — при следующей выгрузке с телефона оно может повториться и всё запутает).
4. В `index.html` замени старое имя файла в `src="..."` на новое. Например:
   ```html
   src="assets/images/delyamer-66k.jpg"
   ```
   меняешь на
   ```html
   src="assets/images/delyamer-new-photo.jpg"
   ```
5. Сохрани файл и открой `index.html` в браузере (просто дважды кликни на файл), чтобы проверить, что картинка встала на место.

## Если нужно добавить новую картинку туда, где её раньше не было

Скопируй одну из существующих строк с `<figure class="placeholder" ...><img ... /></figure>` рядом с нужным местом и поменяй в ней `src` и `alt` на свои.

## Важное правило (чтобы не терять фото при пересылке мне)

Когда присылаешь мне несколько фото за один раз с айфона, все "сохранённые из галереи" картинки часто называются одинаково — `FullSizeRender.jpeg`. На моей стороне сохраняется только последняя из них, остальные теряются.

**Как этого избежать:**
- Присылай такие фото по одному, отдельными сообщениями, **или**
- Если это скриншоты (не сохранённые фото) — они обычно называются `IMG_XXXX` с разными номерами и не перезаписывают друг друга, их можно слать пачкой.

## Структура файлов сайта

```
index.html          — весь текст и разметка сайта
css/style.css        — стили (цвета, шрифты, отступы)
js/script.js          — переключение вкладок и мелкая интерактивность
assets/images/        — все картинки
```

Ничего в `css/` и `js/` трогать не нужно, чтобы заменить фото — только `index.html` и содержимое `assets/images/`.
